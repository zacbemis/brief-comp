# Next language sketches

Programs written in the next language's syntax: `#` symbols, `type`
declarations, modules with signatures, inferred parameter types and inferred
mutability. They are not compiled and may change. The decisions taken so far
are listed in "Language decisions" in
[`docs/plans/architecture.txt`](../plans/architecture.txt).

- [`bank.brf`](bank.brf): the bank example, with module signatures and
  generic modules.
